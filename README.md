# 穗织异闻 · 祟影

柚子社角色同人生存游戏。选择喜欢的角色，在穗织迎战怪潮，招募伙伴、搭配技能与宝物，让熟悉的角色梗变成战斗中的配合。

**[在线试玩](https://zhangliang-04.github.io/hoori-survivors-demo/)** · [更新说明与历史版本](https://github.com/zhangliang-04/hoori-survivors-demo/releases)

## 怎么玩

- WASD／方向键移动，技能自动释放，Esc 暂停；触屏可拖动移动。
- 拾取经验升级技能，收集宝箱选择宝物，逐步构筑队伍。
- 获得其他角色的技能即可邀请她助战；特定组合会形成技能连携和角色共鸣。
- 生存五分钟后迎战祟神，击败祟神获胜。

图鉴可查看技能、宝物与已解锁的角色对话。推荐电脑横屏游玩。
