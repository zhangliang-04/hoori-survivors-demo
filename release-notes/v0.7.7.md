# v0.7.7 · 普通难度与战斗手感调整

## 可选难度

首页默认普通难度，也可选择简单难度。普通难度增加怪潮数量，并提高敌人与Boss的压力；切换角色和重新开始会保留难度选择。

- 新增突祟：预警后沿锁定方向冲锋，可以提前避让。
- 新增咒祟：蓄力后发射直线弹丸，可侧移躲避；蓄力期间击杀可阻止发射。
- 普通难度Boss拥有更多生命、更快的出招和更多召唤物。
- 怪物与咒祟弹丸设有数量上限，密集怪潮采用空间分离优化。

## 开局与芳乃调整

- 基础祟神碎片为16生命，六位自机的初始攻击均可单次命中击杀第一波碎片。第一波生命固定，后续按波次成长。
- 芳乃「祓祟一闪」的多道光束向两侧展开，三级双斩及额外弹道覆盖更宽。

## 验证

通过467项测试，包含六名自机的24局完整对局模拟，以及弹丸命中、躲避、暂停和蓄力打断检查；类型检查、生产构建及浏览器试玩通过。
