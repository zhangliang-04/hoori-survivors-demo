# v0.5.0 · 一起出手，心照不宣

[在线试玩](https://zhangliang-04.github.io/hoori-survivors-demo/)

## 三人的能力，凑成一个构筑

- 丛雨扫地机与黑洞打饺可在同一局解锁。三人赶上配合窗口时，七海把大小饺子投入丛雨身边的黑洞，饺子沿刀圈旋转，随丛雨一起扫荡怪群。
- 任意一方就绪、其余参与技能剩余冷却不超过 3 秒时，可以一起发动。提前释放的时间补回下一次冷却，技能仍保留各自节奏。
- 七海也能中途加入尚未接饺的扫地机：打饺剩余冷却不超过 3 秒、引力场至少剩余 1 秒、距玩家 360 以内且场内有敌人。每个连续存在的引力场只接一轮，续时不重置。
- 分光御守提供的额外黑洞正常释放；三人配合只使用一个移动黑洞。只有普通黑洞与打饺配合时，一轮投掷仍可配合整批黑洞。
- 扫地机黑洞收拢至普通黑洞大小，丛雨丸与笼中鸟在其中收拢，画面更紧凑。保留受控怪物无接触伤害、结束时安全退开的规则。
- 七海打饺各等级基础冷却缩短为 12 秒。

## 角色共鸣：心照不宣

- 丛雨在队时见过绫濑破盾，护盾恢复后触发一次专属小剧场。
- 对白结束后展示「角色共鸣」效果页。绫濑与丛雨获得「心照不宣」：一人命中留下 3 秒标记，另一人接力命中追加本次实际伤害的 50%；每个敌人每秒最多触发一次，本局持续生效。
- 扩散与追加伤害不再次触发共鸣，跳过剧情同样获得效果。战场加入双色标记与斩击反馈。

## 结算展示本局构筑奖励

- 结算分为平级的「技能表现」与「构筑奖励」两栏，采用紧凑布局，窄屏自动纵向排列。
- 技能显示伤害、最终等级、从首次获得起计算的持有时长；治愈之风显示实际减少其他技能冷却的总秒数。
- 「丛雨扫地机」「向黑洞打饺」「向扫地机打饺」分别统计；「心照不宣（绫濑·丛雨）」显示共鸣追加伤害。
- 连携、共鸣与普通技能伤害互不重复，合计为本局总伤害。已解锁但未造成伤害的项目也会保留。

## 验证

- 212 项自动化测试通过，覆盖联动时机、移动弹道、共鸣、冷却抵扣、伤害归属和完整单局模拟。
- 生产构建与本地浏览器试玩通过；已检查结算两栏布局、滚动回退和剧情效果页。
