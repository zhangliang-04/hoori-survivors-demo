# v0.6.0 · 绫地宁宁加入助战

[在线试玩](https://zhangliang-04.github.io/hoori-survivors-demo/)

## 宁宁与她的秘密武器

绫地宁宁来到穗织！获得新技能「魔女的代价」后，宁宁会加入助战，在战场上布置起爆器或桌角，以感应爆炸、持续伤害和减速支援队伍。

- 每次部署随机选择一种秘密武器，两者各有 50% 概率。宁宁寻找空位，停步施法后将道具留在原地；多个装置可以同时存在。
- **起爆器**：范围内连续有敌人停留满 1 秒后爆炸，范围清空则重新计时。感应敌人时闪烁加快，爆炸冲击波覆盖伤害范围；未引爆时最多保留 30 秒。
- **桌角**：在周围形成水渍，持续伤害敌人并降低其 30% 移速，离开后解除减速。水渍基础范围为 120，最多持续 15 秒；多个水渍独立造成伤害，减速不叠加。
- 技能基础冷却为 8 秒，可受冷却加成及治愈之风影响；范围、魔法和通用伤害加成正常生效。

## 首次获得小剧场

首次获得「魔女的代价」时，播放宁宁与绫濑的专属对话：宁宁察觉“代价”即将到来，随后拿出她准备好的秘密武器。

小剧场结束后展示技能说明和宁宁加入助战的提示。点击继续、跳过与暂停沿用现有剧情交互；升级不会重复播放。

## 技能成长与表现

| 等级 | 起爆器伤害 | 起爆器范围 | 水渍每 0.5 秒伤害 |
| ---- | ---------- | ---------- | ----------------- |
| 1    | 120        | 110        | 3                 |
| 2    | 180        | 125        | 4.5               |
| 3    | 300        | 150        | 7.5               |

- 宁宁拥有独立助战立绘、头像、技能图标和施法动作，图鉴与技能面板可查看「魔女的代价」。
- 起爆器与桌角使用独立道具素材，水渍范围可见，持续伤害不会反复制造受击白闪。
- 两类装置造成的伤害统一计入「魔女的代价」的技能统计。
- Debug 模式提供首次剧情、起爆器与桌角的快速试玩入口。
