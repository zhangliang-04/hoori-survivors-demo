# v0.7.0 · 宁宁成为第二位自机

[试玩此版本](https://zhangliang-04.github.io/hoori-survivors-demo/versions/v0.7.0/)

## 宁宁出战

- 首页可选择绫地宁宁或三司绫濑出战。宁宁携带初始技能「魔女的代价」，随机部署起爆器或桌角；部署不降低玩家移动速度。
- 宁宁的被动「魔女形态」不占技能栏。首次等待5秒，之后每10秒变身一次、持续5秒，自动用魔法手枪攻击并击晕敌人；校服与魔女立绘随形态切换。
- 手枪命中可产生发光的白色羽毛。羽毛会向旁边飘出，与经验分开，未拾取的羽毛在8秒后消散。
- 收集20枚羽毛触发「魔女的愿望」，选择一名参战角色强化：每层伤害＋20%、技能冷却－10%，每人最多3层。宁宁作为助战时也拥有这套被动。
- 新增宁宁与相马七绪的出发前小剧场，以及首次为伙伴实现愿望的小剧场。

## 自机与助战配合

- 绫濑作为助战时，首先获得「优雅挥击」，之后可获得「黑洞」。
- 助战绫濑拥有独立护盾：附近敌人会消耗盾值，破盾后强化挥击并触发对应共鸣；这面护盾不会替自机承受伤害。
- 宁宁作为自机时，共鸣追加的秘密武器在玩家当前位置释放，保持移动操作连续。
- 结算中独立展示魔女形态的伤害，并显示角色的愿望强化层数。

## 首页与战斗界面

- 首页角色按钮保留头像与名字，使用角色色和衬线字体。悬浮时在标题与立绘之间展示技能资料卡，并预览对应立绘；移开后恢复已选角色。
- 角色被动移到头像旁，技能连携与角色共鸣集中在血条上方的状态栏，悬浮即可查看说明。
- 精简技能选择、悬浮说明和图鉴文案，突出机制与关键数值。
- 宁宁名字使用银白色，魔女帽图标使用亮银白色，起爆器图标使用粉白色；角色共鸣使用各自的图形图标。
